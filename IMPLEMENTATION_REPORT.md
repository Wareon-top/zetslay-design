## Для Codex

- Публикация: только через установщик и только после решения владельца. На VPS уже не должно быть неуправляемых подключений cabinet-v3, иначе установщик откажет (так задумано).
- Заполненные состояния главной/заказов/сообщений/лотов/событий сверены на синтетическом сервере (см. выше). Формы ответов взяты из того, что реально читают контроллеры хоста; `store-tools`, аналитика, финансы с данными — по-прежнему без фикстур. Для них нужны фикстуры заказов/сообщений/лотов/store-tools в `previews/cabinet-live-review/fixtures.json` (их форму стоит взять из реальных ответов API, а не придумывать).
