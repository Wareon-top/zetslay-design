### P1 — мастер FunPay из подробного окна профиля
Воспроизведено скриптом проверяющего: `dialog.zsf-detail` (нативный, в top layer) перехватывал клики по `.connect-modal`.
Исправление в `app/cabinet-v3/reference-ui.js`: вызовы хоста `setModal(true)` и `setAuthModal(true)` (единственные не нативные оверлеи; остальные окна хоста — `dialog.showModal()` и встают поверх) сначала закрывают общее окно с возвратом перенесённых узлов, затем один раз передают действие контроллеру хоста. Если в редакторе аккаунта есть несохранённые изменения, общее окно не закрывается и показывает своё предупреждение — мастер под ним не открывается.

Регрессия в `scripts/qa-cabinet-v3.py`: настоящий путь пользователя профиль → «Магазин FunPay» → подробное окно → «Подключить FunPay» → мастер получает указатель (`elementFromPoint`) → ввод в поле → закрытие; для подключённого и неподключённого магазина, 1440 и 390.
