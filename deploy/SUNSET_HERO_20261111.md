# Установка согласованного hero V4

Пользователь согласовал 11 ноября 2026 статичную композицию: белый Inter, оранжевый закат, мягкие облака, только объёмный логотип ZetSlay по центру. Исходный макет: `research/implementation/sunset-hero-2026-11-11/` в рабочем пространстве пользователя.

## Состав

- `index.html`: hero заменён; существующая шапка перемещена внутрь сцены с сохранением её ссылок, mobile-menu и data-session-атрибутов.
- `landing-sunset-20261111.css`: стили ограничены `.zsh-hero`; глобальные палитра, типографика, header вне баннера и остальные разделы не переопределяются.
- `assets/hero-sunset-20261111/`: только Z-плитка, фон, локальный Inter и лицензия. WebP сохранены без потерь; декодированные пиксели совпадают с согласованными PNG.
- `deploy/stage-sunset-hero.py`: сохраняет неизвестные дополнения текущей публичной страницы, юридические вставки, SEO, остальные скрипты и разделы; повторная установка даёт тот же HTML.
- `deploy/update-sunset-hero.sh`: точечная установка по полному SHA, предварительная проверка, блокировка, резервная копия, атомарная запись ассетов перед HTML, проверка публичной страницы и файлов. При ошибке после начала записи восстанавливает предыдущие файлы.

API, база, личный кабинет, `.env`, Docker и Caddy не меняются. Перезапуск сервисов не нужен. Нельзя заменять текущий checkout целиком: production содержит дополнения, отсутствующие в базовой ветке.

## Проверки

`python deploy/stage-sunset-hero.test.py`

Проверки на копии реально опубликованного HTML: точное сохранение шапки и всех байтов после hero, прежние теги script, юридические дополнения, идемпотентность. В браузере: адаптивность, один центральный объект, белый заголовок, ссылки, mobile-menu, гостевое и авторизованное состояние на изолированных фикстурах.

## Запуск на VPS

В `/opt/zetslay-site` получить проверенный SHA этой ветки через `git fetch origin SHA`. Извлечь установщик `git show SHA:deploy/update-sunset-hero.sh` во временный файл и запустить `bash файл SHA`. Для проверки без публикации установить `ZETSLAY_SUNSET_PREFLIGHT_ONLY=true`.

Переопределения для изолированных проверок: `ZETSLAY_SITE_DIR`, `ZETSLAY_BACKUP_DIR`, `ZETSLAY_SUNSET_VERIFY_URL` (корневой URL статического сайта), `ZETSLAY_PYTHON`.

При успехе установщик выводит путь архива `/root/zetslay-before-sunset-hero.*.tar.gz`. Ручной откат при необходимости: извлечь именно выведенный архив с `tar -xzf АРХИВ -C /opt/zetslay-site`. Новые версионные ассеты после отката не используются старым HTML и могут оставаться на диске.
