# Отключение объявления о запуске

Удалены только подключения launch-announcement.js/css из app/index.html. Сам JS заменён неактивным файлом для совместимости со старыми HTML из кэша. Новых таймеров, обработчиков и записей в localStorage нет. Остальные уведомления, пробный период, cookie, подключение магазина и объявления центра событий не меняются. CSS и изображения старой кампании могут оставаться на диске без подключений.

Публичный исходный JS 13 ноября побайтно совпал с Git-основой 28279bf86ceab1d0164b69795b851e30e20fa605; SHA256 e18f779d058cf3d14ff4fb146ddea3f9a01d4f9767b6c9b73bd697291e044b40. Публичный index отличается от checkout, поэтому установщик удаляет только два распознанных тега, сохраняя прочие байты страницы.

deploy/update-remove-launch.sh запускается с полным SHA релиза из /opt/zetslay-site. Он использует блокировку обновлений, preflight, проверку версии JS, приватный backup, атомарные записи и HTTP-проверку с откатом при неудаче. API, база и Docker не перезапускаются. Не выполнять git reset/checkout всего проекта ради этого изменения.

В уже открытом кабинете старый JS может оставаться в памяти до перезагрузки. После установки обновить страницу; обычный интерфейс больше не загружает модуль объявления. Установка на VPS требует отдельного подтверждения результатом команды и публичными файлами.
