## Будущая установка

В этой работе VPS не обновлялся: владелец отложил публикацию до общего выпуска. Подготовлены deploy/start-landing-v2.sh, update-landing-v2.py и landing-v2-manifest.json:24 изменяемых файла и22 проверяемые зависимости. Перед записью проверяются известная редакция корневого HTML, все хеши и зависимости. Неизвестные правки сохраняются с отказом. Сначала выкладываются ассеты, последним — index.html; резервная копия приватна. Ошибка HTTP-проверки возвращает прежнюю главную. Ручной rollback сохраняет ассеты для открытых вкладок. Общая блокировка совпадает с установщиком кабинета.

Нельзя копировать весь checkout поверх VPS: реальные контроллеры и юридические документы там новее некоторых Git-файлов. При будущем выпуске применяются проверяемые установщики к фактическим файлам, без замены .env/API/БД и без снятия защиты кабинета.

Для локального просмотра: `node scripts/preview-design.mjs 8140`, затем http://127.0.0.1:8140/ . Сервер только для ревью: в HTTP-ответе заменяет API на локальный signed-out401, не меняет исходные HTML и не проксирует production. /app/ — настоящий frontend с прежней защитой, без демонстрационных фикстур. В продуктовом HTML остаётся https://api.zetslay.pro.
