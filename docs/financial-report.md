# Финансовый отчёт ZetSlay

Раздел «Финансы» отделён от «Подписки». Источник — сохранённый архив заказов выбранного магазина. Чтение отчёта и изменение учётных расходов не запускают запросы FunPay, покупки, выдачу, возвраты или списания.

Расчёт ведётся в целых минимальных единицах RUB / USD / EUR, отдельно по каждой валюте. Оборот — сумма оплаченных заказов, включая впоследствии возвращённые. Доход — оборот за вычетом подтверждённых возвратов. Чистая прибыль — доход минус себестоимость, комиссия FunPay, прочие распределённые расходы и налог, внесённые пользователем. Отменённые заказы без расходов не участвуют в денежных итогах. Неизвестный статус, сумма, частичный возврат или расход не превращается в ноль. Отрицательная прибыль допустима. Итоги по периодам группируются по дате создания заказа, а не по движению денег; прошлый период может уточняться после возврата старого заказа. Доход не равен балансу FunPay и доступной к выводу сумме.

Автоматически учитывается только подтверждённая себестоимость Kosell: записанная аренда или применённое продление и подтверждённые дополнительные расходы в той же валюте. Плановая цена и операции без подтверждённого результата не подменяют расходы. Неопределённые списания/бонусы блокируют окончательный расчёт. Комиссии и налог автоматически не вычисляются. Для других поставщиков и собственного склада себестоимость указывается вручную. Пользователь может явно выбрать ручную себестоимость вместо автоматически обновляемой Kosell.

При неполных расходах общая прибыль остаётся неизвестной; отдельно показывается результат только рассчитанной части и покрытие N из M. Нулевые расходы подтверждаются явным вводом 0. Редактирование сохраняется на сервере по ключу кабинет + магазин + заказ, с номером версии: конкурентное изменение возвращает 409 вместо потери данных. Секреты и содержимое аккаунтов поставщиков в отчёт не передаются.

Периоды: сегодня, вчера, 7 и 30 календарных дней, текущая неделя с понедельника, текущий месяц, вся доступная история, произвольные даты включительно и заказы без точной даты. Границы — московское время UTC+3. Неизвестные даты не угадываются. График группируется по дням/неделям/месяцам; пропуски прибыли сохраняются. На графике максимум 120 интервалов, с явной подписью; итог периода не обрезается. Архив API ограничен 5000 загруженными заказами, ограничение и неполнота исходной истории показаны в интерфейсе.

Поиск и статусы ограничивают таблицу; карточки и график остаются итогами периода и валюты. CSV выгружает весь отфильтрованный список, включая все страницы, сохраняет неизвестные суммы пустыми и экранирует формулы из пользовательского текста для электронных таблиц.

GET /api/v1/finance/report?storeId=… читает отчёт. POST /api/v1/finance/order-costs сохраняет исключительно внутренние учётные поля. Оба действия требуют авторизации, активной подписки/пробного периода и подтверждения принадлежности магазина. Загрузка ограничена по времени, повторные клики не дублируют чтение, запоздавшие ответы не применяются к другой сессии или магазину. При утрате доступа локальные финансовые данные очищаются.

Обновление API запускает общий набор тестов и проверку миграции/конкурентных записей в отдельной PostgreSQL 16. Обновление интерфейса сохраняет существующие модули, авторизацию, исправления синхронизации и раздел «Заказы»; проверяет подготовленные файлы и создаёт резервную копию.
