# Исправления Ультра-плагинов · 26 октября 2026

Проверены Robux Relay, AI Reviews и Ticket Pilot. Исправления сервера и полный отчёт находятся в `Wareon-top/zetslay-core`, ревизия `14606ce8e2583a8fd4904ade6ec3f51426c5fa1c`, файл `docs/ultra-audit-2026-10-26.md`.

- Robux Relay: команды распознаются независимо от регистра; неправильный Unicode-код не сбрасывает сводку; подписи соответствуют категории Ультра.
- AI Reviews: некорректная ручная правка возвращает 422; старое чтение не перезаписывает новые настройки; принятое действие с неудачным последующим чтением не показывается как отклонённое.
- Ticket Pilot: неизвестная дата предыдущего обращения блокирует повтор; чтения до изменения настроек не перезаписывают новое состояние.

Проверки: 1377 серверных тестов прошли, 1 требует отдельной PostgreSQL-среды и локально пропущен; 19 тестов UI прошли; по 4 локальных проверки серверного установщика и установки/отката UI прошли. Docker-проверка серверного COPY-слоя выполняется отдельно в CI для двух режимов сборщика.

`deploy/start-ultra-audit.sh` получает фиксированную серверную ревизию, сначала проверяет совместимость установленного UI, затем устанавливает API и три JS-ресурса. HTML сохраняется, меняются только версии этих подключений. Баннеры видео и прокси остаются. Неизвестные версии исходных файлов останавливают установку до публикации.

Запуск: получить конкретную проверенную ревизию этого репозитория и выполнить из неё `deploy/start-ultra-audit.sh`, задав `ZETSLAY_ULTRA_AUDIT_REVISION` той же ревизией. Каталоги по умолчанию `/opt/zetslay-site` и `/opt/zetslay`. Служба `zetslay-ultra-audit-repair.service`; закрытие журнала не останавливает установку.

Новые разрешения покупок, публикации и отправки не включаются. Установка не выполняет миграции и не меняет тарифы. Прежний контейнер API и копия интерфейса сохраняются. Синтетический probe запускается без сети и секретов; реальных покупок, возвратов, отправок и публикаций при проверке не было.
