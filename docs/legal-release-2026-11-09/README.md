# Редакция документов ZetSlay от 9 ноября 2026 года

Этот каталог содержит черновик для проверки владельцем. `legal/` содержит текущую активную редакцию, которую принимает API. Для просмотра скопируйте два JSON-файла в отдельный каталог и передайте этот каталог в `python deploy/build-legal-pages.py`.

Перед активацией согласуйте фактическое размещение данных и копий, сведения о провайдерах, реквизиты и порядок выполнения запросов на удаление. Для новых аккаунтов согласуйте правило 18+ и порядок остановки публичных карточек до отдельного согласия на распространение. Порядок запуска кабинета и API должен учитывать флаги `ZETSLAY_REGISTRATION_AGE_REQUIRED` и `ZETSLAY_PUBLIC_PROFILES_PAUSED`.

Затем присвойте утверждённой редакции новую версию и дату, сохраните предыдущую в архиве и подготовьте одинаковый манифест для сайта и API. Публикация черновика вместо действующего каталога нарушит проверку версии при акцепте и покупке.
