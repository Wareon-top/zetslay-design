# Proxy offer logo

Replace the offer artwork with the existing ZetSlay logo in the dashboard and guide,
including the dynamically rendered invitation. Use contain fitting so the square mark
remains fully visible on mobile. Purchase controls and dismiss behavior stay unchanged.

The installer patches the current HTML, JavaScript and CSS rather than replacing them
with repository snapshots. It updates cache versions, includes the shared logo asset,
creates a private backup and rolls back partial failures. No API restart is required.
