# Проблемы магазина — второй пакет

Добавлен отдельный рабочий экран: приоритет, причина, последствие, следующий шаг, поиск, фильтры и полнота источников. Неизвестный исход стоит выше нехватки товара и информационных подсказок. Сводка на главной ведёт к текущим проблемам; прочитанные уведомления сохраняются в истории независимо от диагностики. На мобильном список и причина открываются последовательно. Сохранён графитово-оранжевый стиль кабинета.

Данные читает авторизованный GET `/api/v1/diagnostics`. При смене аккаунта/магазина старые результаты скрываются. Запоздалые ответы отбрасываются, зависший запрос ограничен по времени; ошибка сохраняет дату последнего результата. Неполная проверка не обозначается как отсутствие проблем. Навигация в заказ, склад, настройки или плагин не выполняет покупки и выдачу.

Публичное `/demo/#diagnostics` содержит четыре вымышленных примера и работает без API, сессии и хранения данных. Это демонстрация интерфейса, не реальные показатели магазина.

Установка рассчитана **поверх первого пакета** c5e383e frontend / bc04a43 backend. Сначала примените закреплённую инструкцию первого пакета. Затем `deploy/start-diagnostics-release.sh <полный SHA frontend>` подготовит конкретную пару ревизий, проверит совместимость кабинета до изменения API, дополнит текущий API-образ и применит только файлы диагностики/демо. Существующий app.js, вход, платежи, конфигурация и прочие модули сохраняются. Незнакомые варианты файлов останавливают установку. Frontend использует backup, проверку конкурентных изменений и восстановление при частичной записи; backend — существующий механизм отката контейнера. Полная замена checkout не требуется.

Локальные проверки: модель загрузки и изоляции, публичное демо, Python stager/идемпотентность/отказ от неизвестных файлов, валидация проекта. Мобильная ширина 390 px просмотрена в браузере. Полные Linux CI и SQL audit проверяются по окончательному SHA; локальные унаследованные тесты, использующие пути `/C:/` и Unix-утилиты, требуют Linux. Применение на VPS не подтверждено.
