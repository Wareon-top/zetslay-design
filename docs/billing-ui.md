# Финансы · 6 октября 2026

Раздел содержит верхние действия «Пополнить баланс» и «Ввести промокод», отдельные карточки счёта ZetSlay, баланса FunPay и действующего тарифа, сведения о доступных/ожидающих средствах магазина и четыре тарифа из главной страницы. Цены, названия, преимущества и скидки совпадают: 149/299/499/799 ₽ в месяц, −10% за квартал и −20% за год. Показана как месячная стоимость, так и полная стоимость периода. Кнопки тарифов открывают условия выбранного периода внутри кабинета.

## Поддерживаемые действия

- «Обновить данные» использует существующий запрос синхронизации магазина; суммы берутся из снимка выбранного FunPay-аккаунта.
- Текущий доступ берётся из `authState.workspace.plan`. `pro_demo` отображается как демо-тариф и не выдаётся за коммерческий «Профи».
- Неизвестные суммы отображаются как «—». Нулевой баланс, округлённый баланс, валюты и время снимка сохраняются. Суммы доступных и ожидающих средств не придумываются.
- Баланс магазина, текущая подписка и данные модального окна очищаются при выходе/смене сессии. Поздняя ошибка обновления не меняет следующий аккаунт.

## Оплата и промокоды

У текущего API нет эндпоинтов пополнения баланса ZetSlay, оформления коммерческой подписки и применения промокода. Поэтому верхние кнопки открывают окна с обозначением доступности этих функций. Интерфейс не принимает платёжные данные и промокоды, не создаёт фиктивную оплату и не изменяет действующий тариф. Баланс FunPay не используется как баланс оплаты сервиса. Это обновление интерфейса; платёжная интеграция требует отдельного серверного этапа.

## Доставка на существующий VPS

`deploy/update-billing-ui.sh` с переменной `ZETSLAY_BILLING_DESIGN_REVISION`, равной проверенному SHA. Подготовка заменяет только раздел `data-view="billing"` в установленном HTML и добавляет четыре ресурса. Все остальные разделы, API-адрес, модули, обложки и локальные правки сохраняются. Главная страница не меняется. Ссылки регистрации заменены кнопками условий тарифов.

До применения запускаются Python-тесты подготовки, проверки синтаксиса JS и тесты финансового модуля в Node 22 через Docker. Затем создаётся архив `/root/zetslay-site-before-finances.*.tar.gz`. При ошибке копирования выполняется восстановление архива. Перезапуск контейнеров не нужен. После установки — Ctrl+F5.

Повторная установка не дублирует блоки, стили или скрипты. Старый модуль кабинета не заменяется: `billing.js` обновляет только финансовое представление и сохраняет существующие функции маршрутизации/идентификации магазина. Публичные ресурсы тарифов используются в виде идентичных копий внутри кабинета; тест сверяет их и карточки с главной страницей.
