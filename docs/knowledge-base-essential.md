# Короткая база знаний

Вместо 25 материалов оставлены пять: подключение магазина, Golden Key на компьютере, Android, iPhone и помощь при ошибке подключения. Убраны расширенные статьи о плагинах и лишние категории. Сохранены поиск, чтение статьи, оглавление, копирование ссылки и переход в мастер. Старые ссылки `proxy`, `telegram`, `support` направляются в соответствующие краткие инструкции.

Видеобаннер и предложение прокси извлекаются из установленного HTML и сохраняются целиком, с текущими изображениями, текстами, ссылками и атрибутами. Если любой из них отсутствует или неоднозначен, установка останавливается до записи файлов. Остальной кабинет и API не заменяются. Для видео сохранены маркеры совместимости с его отдельным установщиком.

Инструкции проверены 25 октября 2026 по первичным источникам:

- https://cookie-editor.com/ — разработчик Cookie-Editor и официальные магазины.
- https://addons.mozilla.org/en-US/firefox/addon/cookie-editor/ — дополнение cgagnier, поддержка Firefox для Android.
- https://github.com/kiwibrowser/src.next — прекращение поддержки Kiwi после января 2025.
- https://help.kagi.com/orion/browser-extensions/ios-ipados-extensions.html — включение Firefox-расширений и экспериментальный статус поддержки на iPhone.
- https://developer.chrome.com/docs/devtools/application/cookies — способ на компьютере без расширения.

Совместимость Cookie-Editor с конкретной версией Orion не подтверждалась реальным извлечением Golden Key. В статье это явно отмечено, предложен запасной способ на компьютере. Ключ направляется только в поле веб-кабинета ZetSlay, а не в Telegram. Реальные ключи и cookie при проверках не читались.

Проверено: восемь сценариев базы знаний; сохранение баннеров и других разделов, идемпотентность, отказ на неизвестной разметке, возврат после частичной установки. Полный набор проверок app: 661 passed. Совместимость подготовки проверена на HTML, полученном с публичного сайта. В браузере проверены список, чтение и ширина 390 px; горизонтального переполнения списка и статьи нет. Превью содержит только вымышленные данные аккаунта.

Установка: `deploy/update-knowledge-base-essential.sh` с `ZETSLAY_KB_ESSENTIAL_REVISION` из закреплённой ревизии. Файлы копируются в порядке CSS → JS → HTML, перед записью создаётся архив `zetslay-before-kb-essential.*.tar.gz`. Перезапуск API и Docker не требуются. До выполнения команды на VPS изменение остаётся подготовленным в репозитории.
