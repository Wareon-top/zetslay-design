# Админ-панель

Существующий кабинет владельца → «Админ-панель», адрес `/app/#admin`.

Три вкладки: сводка, пользователи, проблемы. Таблица содержит поиск, фильтры, пагинацию и подробную карточку. Карточка показывает тариф и доступ, магазин, личного бота, плагины, последний вход, факт 2FA и синхронизацию. Даты отображаются по Москве. Поля и имена экранируются. При выходе или смене пользователя весь снимок очищается; ответы предыдущей сессии игнорируются.

Доступ проверяется API на каждом запросе по существующему подтверждённому Telegram ID владельца. Скрытая кнопка интерфейса не заменяет эту проверку. Нет localStorage/sessionStorage для админских данных.

Платёжная система не запущена: активный доступ не означает оплату. Срок подписки не хранится и не выдумывается. Панель не выполняет операции в магазинах.

Обновление: `deploy/update-admin-panel-ui.sh` с `ZETSLAY_ADMIN_DESIGN_REVISION`. Четыре файла: `app.js`, `index.html`, `admin-panel.js`, `admin-panel.css`. Остальные страницы и обложки не меняются.
