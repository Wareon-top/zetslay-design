# Обложки плагинов

Рамка карточки возвращена к исходному соотношению **4:2,9**. Пример размера: 1200 × 870 px. Все карточки одинаковы; `object-fit: contain` показывает изображение целиком. Поля остаются у изображений другого соотношения. Баннер на странице «Подробнее» не возвращён.

Владелец каталога (Telegram ID 5062414502 с серверным разрешением) видит кнопку **+** под каждой обложкой без включения отдельного режима. Нажатие открывает выбор PNG, JPEG или WebP. Вход до 10 МБ; оригиналы до 2 МБ и 4096 px сохраняются без повторного кодирования. Для больших файлов действуют прежние пределы размера и высокое качество обработки. Новые изображения не создаются.

Пока загрузка выполняется, следующая загрузка не запускается. Смена сессии до сохранения отменяет запрос. Успешный ответ API сразу обновляет изображение в состоянии; ошибка последующего чтения каталога не объявляет сохранение неудачным. После ошибки можно выбрать тот же файл повторно. Ошибка сохранения сохраняет прежнюю обложку.

`deploy/update-cover-upload-ui.sh` применяет изменения к отдельным фрагментам функций, сохраняет локальные настройки API и других разделов, проверяет JavaScript и тесты загрузки до изменения живых файлов. Перед применением делает архив; неизвестная разметка останавливает обновление.

Подсказка формата в `renderPluginAdminControls` обновляется отдельно от функции: прежние названия кнопок, локальная разметка и проверки владельца сохраняются. Если подсказка отсутствовала, она добавляется в существующую строку кнопок. Дубли подсказок и неизвестная структура останавливают установку до изменения кабинета.

«Автоответчик» и «Telegram-уведомления» исключены из карточек и прямых страниц. Backend дополнительно фильтрует seed, сохранённые метаданные и runtime-записи, а персональный бот исключает старые кнопки. Данные существующих установок в базе не удаляются.

После установки — Ctrl+F5. Чтобы восстановить качество ранее сжатой обложки, требуется повторно загрузить исходный файл: потерянные пиксели из сохранённой копии восстановить нельзя.
