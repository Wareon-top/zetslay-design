# Вход на неделю

Новые сессии email и Telegram (после 2FA, если включена) действуют 168 часов с момента входа. Redis TTL и проверка AccountSecurity остаются обязательными; отзыв устройства, выход и смена эпохи 2FA запрещают восстановление. Чтение страницы не продлевает срок.

`__Host-zetslay_session`: Secure, HttpOnly, SameSite=Lax, Path=/, без Domain, с Max-Age до 604800 и точным Expires сессии. Cookie хранит непрозрачный токен только на API-хосте. JavaScript получает токен для текущего кабинета через POST `/api/v1/auth/resume` с точным Origin из ZETSLAY_ALLOWED_ORIGINS. Секрет не записывается в localStorage/sessionStorage новыми клиентами. Старый sessionStorage используется только при миграции и очищается после проверки. Существующие 12-часовые сроки не удлиняются.

POST `/api/v1/auth/session` проверяет cookie и возвращает только authenticated/expiresAt для кнопки главной страницы. Cookie не авторизует операции магазина, тарифа и плагинов: они по-прежнему требуют явный Bearer. При наличии cookie она имеет приоритет над токеном старой вкладки. Вход/выход между вкладками передаёт только публичное уведомление; новое состояние подтверждается сервером.

Выход отзывает серверную сессию и очищает cookie. Старый Bearer не удаляет cookie другого входа. Клиент ждёт подтверждения до 12 секунд; при сбое сети показывает возможность повторить, а не сообщает об успешном выходе. Ошибка сети при восстановлении не уничтожает действующую сессию.

Обновление: `deploy/update-week-session.sh`, затем frontend `deploy/update-week-session-ui.sh`. Backend запускает полный suite в отдельном plugin-audit образе без production env, сети и томов. Frontend меняет только участки авторизации и кнопки входа; локальные оформления сохраняются. Каждый updater создаёт backup и откатывает свои изменения при ошибке. Контейнер Docker/реальный браузер в среде разработки недоступны; HTTP интеграции проверены локальным сервером, UI — DOM/VM harness. Проверка на VPS использует Node 22.

В общем прогоне обнаружена и исправлена существовавшая до задачи несовместимость diagnostic test с отсутствовавшим export `selectSavedProxy`; выбор сохранённого прокси остаётся только чтением и не возвращает расшифрованные данные.
