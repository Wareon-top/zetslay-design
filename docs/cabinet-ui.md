# Оформление кабинета · 6 октября 2026

Новая навигация, верхняя панель, карточки статистики, таблицы заказов и товаров, диалоги и профиль оформлены одним слоем `app/cabinet-ui.css`. Фон — графитовый, поверхности — нейтральные, активные элементы — оранжевые. Второстепенный текст стал контрастнее, основные действия и поля — крупнее. На телефоне меню остаётся выдвижным, шапка компактнее, а сообщения используют существующий переход между списком и перепиской.

JavaScript кабинета и API не меняются. Сохранены проверка сессии перед показом кабинета, административные ограничения, аватарка магазина и индикатор подключения, фактические балансы и даты. Новый слой не задаёт размер обложек, не возвращает баннер на страницу плагина и не меняет плотность сетки каталога. Мастер подключения сохраняет собственное оформление.

## Установка на существующий VPS

Запускайте `deploy/update-cabinet-ui.sh` из `/opt/zetslay-site` с `ZETSLAY_CABINET_DESIGN_REVISION`, равным проверенному SHA коммита. Скрипт читает установленный `app/index.html`, проверяет структуру и добавляет последнюю ссылку на новый CSS. Остальные строки HTML, адрес API и все модули сохраняются. Повторный запуск не дублирует ссылку. До применения выполняются тесты подготовки обновления. Архив старого HTML и старой версии нового CSS сохраняется в `/root/zetslay-site-before-cabinet-ui.*.tar.gz`. При ошибке копирования скрипт восстанавливает этот архив. Перезапуск Docker не требуется.

При ручном откате распакуйте архив из `/opt/zetslay-site`: `tar -xzf /root/ИМЯ_АРХИВА.tar.gz`. Если это первая установка, новый CSS может остаться на диске; восстановленный HTML на него не ссылается. Затем обновите страницу через Ctrl+F5.

## Проверка

- `python3 deploy/stage-cabinet-ui.test.py` — сохранение локальных правок и модулей, скрытых блоков и API; повторная установка; остановка при неизвестной структуре или пустом файле.
- `node --test app/*.test.mjs` — существующие проверки кабинета, плагинов, заказов, переписки, профиля, прав и подключения.
- `bash -n deploy/update-cabinet-ui.sh`.

В этой среде браузерная визуальная проверка недоступна. После установки проверьте кабинет на широком экране и телефоне: меню, баланс, прокрутку таблиц, выбор диалога, страницу плагина и мастер подключения.
